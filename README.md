# DownForAll

Android app that downloads videos (or just their audio) from YouTube, Facebook, Instagram and TikTok links. Everything runs on the phone — no server needed.

## Download

Get the latest APK from **[Releases](../../releases/latest)** (`downforall-vX.Y.apk`).

## Install

1. Download the APK on your Android phone (Android 8.0 or newer).
2. Open it. If asked, allow your browser or file manager to **install unknown apps**.
3. New versions install over the old one — no need to uninstall.

## Use

Share a video from the YouTube, Facebook, Instagram or TikTok app → **DownForAll**, or paste a link. Pick a quality and tap **Download**. Files are saved to `Movies/DownForAll` (video) or `Music/DownForAll` (audio). If YouTube downloads stop working, open **Settings → Update yt-dlp**.

Built on [yt-dlp](https://github.com/yt-dlp/yt-dlp) and [youtubedl-android](https://github.com/yausername/youtubedl-android).
